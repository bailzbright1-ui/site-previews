# 09 · Atelier Meridian: contemporary art museum

**Family:** Quiet Gallery · **Best for:** galleries, museums, artists, architects, publishers
**Source:** https://dribbble.com/shots/27306724-Museum-Website-Design-Atelier-Meridian (Phenomenon Labs for Phenomenon Studio)
**Look at:** `images/09-atelier-meridian-hero.jpg` (artist index hover), `images/09-atelier-meridian-sheet.jpg`

## Feel
A white cube. Swiss restraint where the art provides every colour.

## Palette (roles)
| Role | Hex |
|---|---|
| Page | `#FFFFFF` / `#F3F4F5` |
| Ink | `#000000` |
| Inactive text | cool grey `#BAC4C2` |
| Colour | only from artworks and gallery photos |

## Type
- Swiss neo-grotesk, regular weight, large sentence-case headings, tight tracking.
- Tiny **outlined rectangular tags** ("About", "Featured artists", "Upcoming Exhibition").
- Free fonts: **Inter Tight 400** or **Hanken Grotesk 400**.

## Layout & components
- Nav links grouped inside one light-grey rounded bar, top-right.
- Hero: a row of gallery photos with **deliberately uneven heights, top-aligned**, under a split intro (tag + short line left, title + paragraph + black Subscribe right).
- **Artist index**: huge centred names stacked between hairline rules. All are grey except the hovered one in black, with an artwork thumbnail floating beside the cursor and a one-line bio right-aligned.
- Events carousel with a thin progress bar instead of dots.
- Strict grid, hairline dividers, no shadows, no decoration.

## Signature move
A hover-reveal index list where the type is the navigation and the image appears on hover.

## Borrow
- Index lists for any collection (team, services, projects, menu).
- Progress-bar carousels.
- Uneven image heights for an editorial rhythm.

## Don't copy
Real artist names, artworks or the Atelier Meridian name.
