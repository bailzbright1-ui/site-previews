# 14 · Elevate: fashion e-commerce

**Family:** Quiet Luxury · **Best for:** fashion, apparel, multi-brand stores, editorial catalogues
**Source:** https://dribbble.com/shots/27013902-Modern-E-commerce-Website-Design (Ronas IT | UI/UX Team)
**Look at:** `images/14-elevate-hero.jpg` (catalogue grid), `images/14-elevate-sheet.jpg` (product page + brand sheet)

## Feel
Editorial fashion restraint. A monochrome frame where the clothes are the colour.

## Palette (roles)
| Role | Hex |
|---|---|
| Page | `#FFFFFF` |
| Image wells | `#ECECEC` |
| Ink | `#0B0B0B` |
| Secondary text | `#8F8F8F` prices |

## Type
- Helvetica / Neue Haas. The page title is a big regular-weight brand name ("Maison Margela"). **Everything else is tiny UPPERCASE** (nav, filters, product names), with prices right-aligned in grey.
- Free fonts: **Inter** or **Hanken Grotesk** at 400 only.

## Layout & components
- Header: a black pill "MENU ≡" top-left, WOMEN / MEN, a centred wordmark, SEARCH / CATALOG / CART (count in a black dot) / PROFILE on the right.
- **Uneven catalogue grid**: 4 columns where tall model shots and short product shots sit together, so rows go deliberately uneven (masonry).
- Category filter row right-aligned with a filter icon.
- Product page: a full-height model photo, vertical thumbnail strip, title + price, **spec table of hairline rows** (Material / Brand / Strap), quantity stepper beside a full-width black "ADD TO CART" bar, uppercase breadcrumbs.

## Signature move
An editorial masonry catalogue on pale grey wells, with all UI in micro caps.

## Borrow
- Mixed-height product grids for visual rhythm.
- Spec tables with hairlines instead of bullet lists.
- A black pill menu button as the only "shape" in the header.

## Don't copy
Real fashion brand names (the shot uses a real designer's products) or product photos.
