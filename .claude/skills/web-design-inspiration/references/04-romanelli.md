# 04 · Mirko Romanelli: industrial designer portfolio

**Family:** Swiss Scale Contrast · **Best for:** portfolios, designers, makers, studios, product brands
**Source:** https://dribbble.com/shots/25454547-Portfolio-Website-Design-Marketing-Website-Web-Design and https://dribbble.com/shots/27566031-Website-Design-for-Industrial-Designer-Mirko-Romanelli (Shakuro, the same project posted twice)
**Look at:** `images/04-romanelli-sheet.jpg`, `images/04-romanelli-sheet-2.jpg`, `images/04-romanelli-detail.jpg` (project page)

## Feel
Gallery-quiet and very confident. The work speaks, and the type shouts only once per page.

## Palette (roles)
| Role | Hex |
|---|---|
| Canvas | `#EFEFEF` / `#E7E7E8` |
| Ink | `#111415` |
| Colour | comes **only** from the product renders: sage `#B8C5B8`/`#768977`, petrol `#2F4E56`, terracotta |

## Type
- Display: enormous **lowercase**, tightly tracked bold grotesk (`letter-spacing: -0.06em`, `line-height: 0.85`) used as the page name.
- Everything else is tiny (12–14px) regular-weight text.
- Free fonts: **Inter Tight 700** or **Hanken Grotesk 700** for display, the same family at 400 for text.

## Layout & components
- The page title word ("mirko romanelli", "works", "about") is **anchored to the bottom-left corner of the viewport** at 15–20vw.
- Works page: a loose collage of thin-bordered rounded frames holding soft 3D product renders, at mixed sizes.
- About: a small B&W portrait centred, with a quiet CV list beside it and a pull-quote top-left.
- Project page: an edge-to-edge image pair (or triptych), a short paragraph in a narrow column, date and category bottom-left, "Next project" bottom-right with the next project's name.

## Signature move
Radical scale contrast: one giant lowercase word against micro text, with nothing in between.

## Borrow
- Page names as typographic objects instead of hero banners.
- "Next project" navigation that previews what's next.
- Letting the work set the palette while the UI stays grey.

## Don't copy
The designer's name, his products or the renders.
